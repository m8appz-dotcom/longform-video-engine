# Referencias del nicho

Deja aqui links, capturas o notas de reels que estan funcionando en tu nicho.
El director (skill reel-director) las revisa ANTES de la audicion de guion y
extrae observaciones de FORMATO (hook, densidad de cortes, tratamiento visual,
duracion) a `meta.benchmark_notes` del plan.

Reglas:
- Formato, nunca contenido: el skill no copia frases, guiones ni claims.
- Carpeta vacia = el skill sigue con sus reglas base y lo declara.
- Renueva las referencias cada pocas semanas: el formato que funciona caduca.
